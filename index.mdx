Fly Brain is a whole-brain leaky integrate-and-fire (LIF) simulation of the adult *Drosophila melanogaster* brain, built from the [FlyWire](https://flywire.ai/) connectome with approximately 138,000 neurons and 5 million synapses. It lets you activate or silence arbitrary neuron populations and observe the resulting spike propagation — and benchmark that simulation across six interchangeable computational backends on CPU and GPU.

## What You Can Do

Fly Brain supports two types of neural manipulations on any subset of FlyWire neurons:

- **Activation** — drive target neurons with Poisson spiking at a fixed frequency (optogenetic activation model)
- **Silencing** — zero out all synaptic connections to and from a set of neurons (optogenetic silencing model)

Every backend produces identical spike-timing outputs in a canonical Parquet schema, so you can compare results across frameworks at any scale.

## Getting Started

<Steps>
  <Step title="Create the conda environment">
    Install the `brain-fly` environment, which includes Brian2, Brian2CUDA, PyTorch (CUDA), NEST GPU, and GeNN:
    ```bash
    conda env create -f environment.yml
    conda activate brain-fly
    ```
  </Step>
  <Step title="Run a quick benchmark">
    Simulate 1 second of brain activity across all five main-environment backends:
    ```bash
    python main.py --t_run 1 --n_run 1 --no_log_file
    ```
  </Step>
  <Step title="Review results">
    Timing results are saved incrementally to `data/benchmark-results.csv`. Spike outputs land in `data/results/` as Parquet files.
  </Step>
  <Step title="Run the paper suite">
    Reproduce the full Nature paper benchmark grid (5 rounds, 4 durations, 5 trial counts):
    ```bash
    python main.py --paper --run-label my_run
    ```
  </Step>
</Steps>
